# Configurações

Esta pasta contém exemplos de arquivos de configuração utilizados na documentação do projeto.

Os arquivos públicos devem mostrar a estrutura real necessária para reproduzir a instalação, mas não devem conter informações privadas do TuxFreeTech.

## Regra

Antes de publicar qualquer configuração:

- remover senhas;
- remover tokens;
- remover chaves;
- substituir caminhos reais por exemplos;
- substituir endereços internos quando não forem necessários;
- revisar volumes e nomes específicos da infraestrutura.

Os exemplos serão preenchidos a partir das versões reais utilizadas durante o projeto.

A documentação não deve inventar configurações apenas para deixar um exemplo completo.
